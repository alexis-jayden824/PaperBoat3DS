# M8 — Input Backend

**Goal:** native 3DS HID → PaperBoat `OSContPad`, without `3ds.h` in
PaperBoat-facing code. **SELECT is reserved** for the future bottom-screen
menu (M16) and never appears in the N64 pad.

## Mapping

| 3DS | N64 (`os_cont.h`) |
|---|---|
| A | A (`0x8000`) |
| B | B |
| START | START |
| D-pad | D-pad |
| Circle Pad | Analog stick (`int8`, deadzone 15, ±156 → ±80) |
| L or ZL | Z |
| R | R |
| X or C-stick up | C-Up |
| Y or C-stick left | C-Left |
| ZR or C-stick down | C-Down |
| C-stick right | C-Right |
| SELECT | **not mapped** (M16) |
| Touch | not mapped |

L maps to Z so Old 3DS (no ZL) can still use partner/Z actions. New 3DS
C-stick digital bits are taken from `hidScanInput` when present. Analog
C-stick (IRRST) is not initialized; New 3DS clock/L2 extras stay off.

`source/platform.c` still owns libctru HID (`hidScanInput`, circle/C-stick).
`source/gfx_pica.c` owns citro3d. `source/input.c` maps bits.
`pb_compat_poll_controller` reads the last HID sample so `main` and the
engine share one scan per frame.

## Shell

START still exits this Homebrew shell. SELECT logs `SELECT reserved (M16)`
and does not quit.

## Host contract

```sh
sh tools/test_m8.sh
```

CI still uploads `.3dsx`, `.3ds`, and `.cia` only.

## What M8 forbids

- Mapping SELECT into `PBOSContPad`.
- Including `3ds.h` from `input.c` / `compat.c` / `main.c`.
- SDL or desktop libultraship controller backends.
- Claiming the PaperBoat menu exists (M16).
