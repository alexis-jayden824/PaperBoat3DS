# M11 — Graphics Backend Foundation

**Goal:** stand up a **PICA200 / citro3d** command path with a CPU vertex
clip, Fast3D **invertY**, 320×240 source framed in 400×240 with **40 px
pillars**, texture upload, a depth buffer on the top target, and
diagnostics.

This is **not** a Fast3D interpreter and **not** the title screen. It does
not draw Paper Mario geometry. `Graphics_PushFrame` records a display list
pointer without decoding GBI commands (M13).

## Layout

| Piece | Role |
|---|---|
| `include/pb3ds/gfx.h` | Source/top sizes, clip, invertY, submit, tex, diag |
| `source/gfx.c` | Portable clip/project/submit (no `3ds.h`) |
| `source/gfx_pica.c` | citro3d init, command buffer, depth RT, tex upload |
| `source/compat.c` | `Graphics_PushFrame` → `pb_gfx_submit_dl` (ready) |

libctru lifecycle (`gfxInitDefault`, bottom console) stays in
`source/platform.c`. GPU command lists live in `gfx_pica.c`.

## Framing

| Constant | Value |
|---|---|
| `PB_GFX_SOURCE_WIDTH` × `HEIGHT` | 320 × 240 |
| `PB_GFX_PILLAR_PX` | 40 |
| `PB_GFX_TOP_WIDTH` × `HEIGHT` | 400 × 240 |

Clip volume is N64/Fast3D: `|x|,|y|,|z| ≤ w` with `w > 0`. invertY negates
clip Y before mapping into source pixels, then pillars shift X by 40.

On device, the top render target is **240×400** (PICA orientation) with
`GPU_RB_RGBA8` color and `GPU_RB_DEPTH24_STENCIL8`. `C3D_FrameBegin` /
`C3D_RenderTargetClear` / `C3D_FrameEnd` is the command-submission loop.
picasso shaders are **not** in this milestone, so no triangle raster.

If citro3d init fails, the shell falls back to the M0 CPU RGB888 clear.

## Host contract

```sh
sh tools/test_m11.sh
```

## What M11 forbids

- Fake Toad Town / title / overworld meshes.
- Interpreting Fast3D (M13).
- Desktop GL/Vulkan/SDL GPU backends.
- Linking `boot_main`.
- Claiming M12 title-screen assets are on screen (bind is M12; raster is M13).

M11 is complete when the host contract passes and CI still uploads `.3dsx`,
`.3ds`, and `.cia` linked with `-lcitro3d`. Hardware proof that citro3d
clears the top LCD is owner evidence, same class as M0 boot.
