# M13 — Full PaperBoat Runtime + Renderer Integration

**Goal:** one APT gameplay loop that can drive PaperBoat
`step_game_loop` / `gfx_draw_frame`, interpret F3DEX2 display lists, decode
N64 textures (including CI/TLUT), map combiners to PICA TEV, and present
the 320×240 source in the 400×240 top framebuffer.

PaperBoat remains the source of game state. This tree does not reconstruct
Toad Town, Mario, or menus as stand-in geometry. `PBWorldScene` is not used.
`boot_main` is **not** called (it waits forever on nuGfx).

## Pipeline

```
HID → pb_runtime_frame
        ├─ (no game objects / no o2r) title bind + teal shell
        └─ PB3DS_GAME_OBJECTS && both .o2r
              step_game_loop → gfx_draw_frame
                    Graphics_PushFrame
                          pb_f3d_execute
                                pb_tex_cache_get / pb_tev_set_combine
                                pb_gfx_submit_vertices
                                      GfxRenderingAPI3DS (gfx.c + gfx_pica.c)
                                            citro3d / PICA200 → top LCD
```

## What CI actually links

The default Homebrew binary still does **not** compile the thousands of
PaperBoat gameplay translation units (LUS/`common.h` surface, owner `.o2r`).
`tools/list_paperboat_sources.sh` emits the same CMake exclusion list as
`upstream/PAPERBOAT.exclusions` so an owner can opt in:

```sh
make CFLAGS+=-DPB3DS_GAME_OBJECTS
```

Playing is true only when that define is set **and** `paperboat.o2r` plus
`pm64.o2r` are on SD (`sdmc:/3ds/PaperBoat3DS/`). Until then START still
exits the shell. While playing, quit is **L+R+START**. SELECT stays
reserved for M16.

## Fast3D

`include/pb3ds/f3d.h` is a public F3DEX2 opcode map (no SGI `gbi.h`).
Implemented or explicitly skipped with a one-shot `unsupported` log:

VTX, TRI1 (w0 indices), TRI2, QUAD, DL, MTX load/mul/push, POPMTX,
GEOMETRYMODE, SETTIMG/SETTILE/SETTILESIZE/LOADBLOCK/LOADTILE/LOADTLUT,
SETCOMBINE, colors, SETSCISSOR (clamped), TEXRECT extra-word skip,
SETOTHERMODE, FILLRECT counted but not drawn (avoids a black depth quad),
ENDDL.

Host 64-bit: `Gfx.w1` cannot hold pointers; slots 1–7 of the segment table
are used (`pb_f3d_set_segment`).

## Textures

`source/tex.c` decodes RGBA16/32, IA4/8/16, I4/8, CI4/8. Missing TLUT fills
visible grey (`0x40`) with opaque alpha and increments `black_prevented`.
Cache: 16 slots, 256 KiB, LRU, key includes palette CRC.

PICA upload is **one** path in `gfx_pica.c`: 8×8 Morton tile + ABGR, linear
buffer, `C3D_TexUpload` / flush. No second swizzle implementation.

## TEV

`source/tev.c` unpacks SETCOMBINE into cycle 0/1 muxes and maps TEXEL0×SHADE,
replace, primitive, and shade. Unknown combiners log both words (up to 8)
and fall back to **modulate**, never black.

## Frame / depth / orientation

`pb_gfx_begin_frame` / draw / `pb_gfx_present` is the command loop. Depth
is `GPU_RB_DEPTH24_STENCIL8` cleared with color (no visible fullscreen
depth rectangle). invertY and upright T each apply once
(see `include/pb3ds/gfx.h`). Scissor is clamped in source space then
converted +40 px for pillars.

`shaders/default.v.pica` is a clip-space passthrough assembled by picasso
(the file lives under `shaders/`, not `source/`, so M11’s “no vendored
picasso in source/” contract still holds).

## Audio / save / bottom menu

Unchanged stubs (M14 / M15 / M16). CVars remain defaulting.
