# M3 — 3DS Platform Abstraction

**Goal:** give PaperBoat-facing C a platform API so later milestones never
include `3ds.h`. This is the service surface, not the full backends.

## Boundary

| Header | Role | Later owner |
|---|---|---|
| `include/pb3ds/gfx.h` | 400×240 / 320×240 sizes, clear/present | M11 citro3d |
| `include/pb3ds/input.h` | HID bit layout, poll sample | M8 mapping |
| `include/pb3ds/fs.h` | `sdmc:/3ds/PaperBoat3DS/` path constants | M9 I/O |
| `include/pb3ds/time.h` | millisecond clock, vblank wait | M10 loop |
| `include/pb3ds/memory.h` | application/linear free, Old 3DS reserves | M4 accounting |
| `include/pb3ds/log.h` | leveled sink | M4 diagnostics |
| `include/pb3ds/audio.h` | status enum only | M14 ndsp |
| `include/pb3ds/thread.h` | extra workers forbidden | M10 |
| `include/pb3ds/system.h` | init / APT pump / shutdown / console | M0/M10 |
| `include/pb3ds/platform.h` | aggregate include | — |

`source/platform.c` is the only translation unit allowed to include `3ds.h`.
Host builds (`!__3DS__`) provide stubs so contracts run without libctru.

## Explicit deferrals

- `pb_audio_status()` returns `PB_AUDIO_DEFERRED_M14`. No ndsp, no mixer.
- `pb_fs_status()` returns `PB_FS_DEFERRED_M9`. Paths are named, not opened.
- `pb_thread_extra_workers_allowed()` is always false. PaperBoat is stepped
  from the APT main loop so suspend/resume stay on one ARM11 context.
- HID bits match libctru `KEY_*` (START is `1 << 3`). Analog stick and
  SELECT-as-menu policy are M8.
- Framebuffer clear is RGB888 via libctru. PICA command lists are M11.

## Application

`source/main.c` includes only `pb3ds/platform.h` and `version.h`. It still
draws a solid teal top screen and a bottom status console. That is not
PaperBoat.

## Host contract

```sh
sh tools/test_platform.sh
```

Checks: no `3ds.h` in `include/pb3ds` or `main.c`; audio deferred; extra
threads forbidden; START bit; SDMC root; host init/poll/shutdown.

## What M3 forbids

- Including `3ds.h` from game, compatibility, or `main.c`.
- Extra OS worker threads.
- Compiling PaperBoat (M5) or linking desktop SDL/libultraship.
- Claiming audio or SDMC I/O work.

M3 is complete when this API is committed, the host contract passes, and CI
still produces `.3dsx` and `.3ds`. Hardware boot of the shell remains M0
owner evidence.
