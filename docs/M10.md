# M10 — Timing, Game Loop & Runtime Services

**Goal:** step PaperBoat from the APT main loop at **30 Hz**, with a
monotonic clock that **pauses across HOME/sleep**, no extra OS threads, and
no desktop window pump.

This does **not** call `boot_main`. Graphics remain the M0/M3 framebuffer
clear.

## Clock

`pb_time_raw_ms()` is `osGetTime` (host: a settable counter).
`pb_time_ms()` is raw time minus origin minus time spent suspended/asleep.

HOME suspend and sleep freeze game time. Restore/wakeup drops the gap so
the next frame does not fast-forward.

## Frame step

| Constant | Value |
|---|---|
| `PB_LOOP_TICK_HZ` | 30 |
| `PB_LOOP_TICK_MS` | 33 |
| `PB_LOOP_MAX_CATCHUP` | 2 |

`pb_loop_begin_frame()` returns how many game ticks to run this display
frame (0 while paused). `GameEngine_HoldFrame` waits one vblank.
`pb_loop_desktop_window_allowed()` is false. Extra workers stay forbidden.

## Host contract

```sh
sh tools/test_m10.sh
```

## What M10 forbids

- SDL/GLFW/`PollEvent` game loops.
- Extra `threadCreate` workers for the game.
- Enabling New 3DS clock/L2.
- Claiming the title screen or renderer is running (M11+).
