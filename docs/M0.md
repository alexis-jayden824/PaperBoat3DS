# M0 — Native 3DS Bootstrap

**Goal:** the smallest legitimate native 3DS application.

## In this tree

| Piece | Location |
|---|---|
| ARM11 entry + APT loop | `source/main.c` |
| Portable lifecycle / log | `source/bootstrap.c` |
| Host contract | `tests/test_bootstrap.c` |
| `.3dsx` Makefile | `Makefile` |
| CCI `.3ds` RSF | `packaging/PaperBoat3DS-Refolded.rsf` |

## Behavior

- `gfxInitDefault` brings up both LCDs.
- Top screen is filled with a solid teal. This is not a title screen and not
  Paper Mario.
- Bottom screen is a `PrintConsole` with project name, version, frame count,
  lifecycle, and a rolling log.
- START sets the portable exit flag and `main` calls `gfxExit`.
- APT suspend/sleep/restore/exit update the same lifecycle state used by the
  host tests.

## Acceptance

- [x] Host contract for init, APT, START-exit, and the "not PaperBoat" log
- [x] `.3dsx` and `.3ds` produced by CI (owner still needs to boot them)
- [ ] Application boots on Citra/Folium or hardware
- [ ] START exits without a hang
- [ ] No PaperBoat/runtime symbols, no fake overworld

M0 is not complete until a 3DS-compatible runtime has actually booted the
artifact. The host tests do not replace that evidence.
