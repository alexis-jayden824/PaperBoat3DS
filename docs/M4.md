# M4 — Memory, Logging & Diagnostics Foundation

**Goal:** make the shell observable on Old 3DS: heap/linear pressure, a log
ring, assertions, crash breadcrumbs, runtime status, and New 3DS detection
without turning New 3DS extras on.

## What landed

| Piece | Location |
|---|---|
| Memory pressure | `include/pb3ds/memory.h`, `pb_memory_query` |
| Log ring | `include/pb3ds/log.h` |
| Assertions | `include/pb3ds/assert.h` (`PB_ASSERT`, no abort) |
| Breadcrumbs | `include/pb3ds/diag.h` |
| Runtime snapshot | `pb_runtime_query` |
| New 3DS detect | `include/pb3ds/hw.h`, `APT_CheckNew3DS` in `platform.c` |
| Host contract | `tests/test_diag.c`, `tools/test_m4.sh` |

`source/diag.c` is portable C. `3ds.h` stays in `source/platform.c`.

## Memory

Old 3DS is the budget even on New 3DS hardware:

- application reserve: 8 MiB
- linear reserve: 4 MiB

Pressure is `unmeasured` / `ok` / `warning` (below reserve) / `critical`
(below a quarter of reserve). Host tests inject free bytes through
`pb_memory_host_set`.

## New 3DS

`pb_hw_model()` reports `old3ds` or `new3ds` after APT detection.
`pb_hw_new_3ds_features_enabled()` is always false. M4 does not call
`osSetSpeedupEnable` or raise APPCORE time. Extra RAM does not raise the
memory budget.

## Assertions and breadcrumbs

`PB_ASSERT` records file/line/expression, pushes a breadcrumb, and logs an
error. It does not abort: a hung assert is worse than a visible failure on
the bottom screen. APT suspend/sleep/exit also drop breadcrumbs.

SDMC log files wait for M9. This ring is RAM-only.

## Application

The bottom console shows hardware model, n3ds-features flag (0), memory
pressure, assert flag, and the last breadcrumbs. Still not PaperBoat.

## Host contract

```sh
sh tools/test_m4.sh
```

## What M4 forbids

- Enabling New 3DS clock/L2 as a silent default.
- Compiling PaperBoat (M5).
- Writing logs to SD (M9).
- Replacing the game with fake geometry.

M4 is complete when the host contract passes and CI still produces `.3dsx`
and `.3ds`. Hardware boot remains M0 owner evidence.
