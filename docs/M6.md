# M6 — libultraship / Engine Compatibility Layer

**Goal:** give PaperBoat a **C** engine surface so later game TUs can link
without desktop libultraship, SDL, ImGui, or extra OS threads. Missing
backends fail **explicitly** (status codes + `pb_compat_unsupported`).

This does **not** run `boot_main`. It does not implement Fast3D.

## Contracts

| Surface | M6 behavior | Later owner |
|---|---|---|
| Logging | `GameEngine_Log*` → `pb_log` (ready) | M4 |
| Resources | `ResourceGetDataByName` via `pb_fs_lookup` | M9 |
| Controller | `pb_input_map_n64` → `PBOSContPad` (ready) | M8 |
| Time / hold | `pb_time_ms` + `pb_loop_hold_frame` | M10 |
| Gfx submit | `Graphics_PushFrame` no-op | M11–M13 |
| Audio frame | start/end no-op | M14 |
| Config | CVars return defaults, ignore sets | M15 |
| Desktop engine | `pb_compat_desktop_engine_allowed()` is false | never |

`src/port/nusys_overrides.c` is **not** compiled. It belongs to the desktop
engine. M6 owns the symbols, not that file’s SDL-era bodies.

## Packaging

`make packages` now emits:

- `.3dsx` Homebrew Launcher
- `.3ds` CCI (`-f cci`, UniqueId `0xF0B43`)
- `.cia` installable (`-f cia`, same RSF, unencrypted `-target t`)

CIA also uses the same RSF (UniqueId `0xF0B43`, unencrypted `-target t`).
A HOME-menu CGFX banner is optional later; makerom does not require
`bannertool` for the installable CIA.

## Host contract

```sh
sh tools/test_m6.sh
```

## What M6 forbids

- Linking JeodC/libultraship or SDL.
- Pretending O2R lookup, PICA submit, or ndsp work.
- Compiling `Game.cpp` / `Engine.cpp`.

M7 is the host asset pipeline; M6 does not extract archives.

M6 is complete when the host contract passes and CI uploads `.3dsx`, `.3ds`,
and `.cia`.
