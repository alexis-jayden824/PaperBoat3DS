# M12 — Authentic Title-Screen Integration

**Goal:** bind PaperBoat 1.0.1’s **prepared title-screen resources** by the
same OTR names and US sizes the game uses, keep **upright texture T**, and
step the title scene states. This does **not** rasterize the logo.

`state_title_screen.c` is not compiled. `boot_main` is not linked. Missing
`.o2r` files leave the scene in `waiting`. Bound host-test blobs are size
checks, not Nintendo art.

## PaperBoat names (US)

From `assets/yaml/us/title_screen.yml` and `state_init_title_screen`:

| OTR name | Format | Size |
|---|---|---|
| `__OTR__title_screen/title_logo` | RGBA32 200×112 | 89600 |
| `__OTR__title_screen/title_copyright` | IA8 144×32 | 4608 |
| `__OTR__title_screen/title_press_start` | IA8 128×32 | 4096 |
| `title_bg` | map background | optional |

Lookups also try the `_img` suffix (`port_named_image`) and the name with
`__OTR__` stripped. Byte size must match or the bind is rejected.

US logo placement in 320×240 source is **(60, 15)** as in PaperBoat
(`TITLE_POS_LEFT` / `TITLE_POS_TOP`). Pillars map that to **(100, 15)** on
the 400×240 top LCD. Full framing/UV display correction remains **M12.1**.

## Orientation

`pb_gfx_upright_t(t) = 1 - t`. Title logo UVs are `(s0,t0)=(0,1)` and
`(s1,t1)=(1,0)` so T is upright relative to Fast3D invertY. No substitute
quad is submitted.

## Scene

`waiting` → `init` → `appear` (3 ticks, PaperBoat `TitleScreen_AppearDelay`)
→ `hold`. `pb_title_presented()` stays **false** until Fast3D (M13) can
draw the bound images. M13 submits those images through Fast3D when a display
list names them; CI still does not ship Nintendo pixels.

START still exits the Homebrew shell. It does not enter file select.

## Host contract

```sh
sh tools/test_m12.sh
```

## What M12 forbids

- Inventing title/logo/Toad Town vertices or pixels.
- Compiling `state_title_screen.c` or calling `boot_main`.
- Claiming the title is on the top LCD (`presented` is false).
- Committing `.o2r` / ROM data.
