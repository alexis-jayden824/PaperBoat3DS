# PaperBoat3DS

An experimental native Nintendo 3DS port of PaperBoat.

## Status

Active development follows the documented [M0-M24 roadmap](docs/ROADMAP.md)
on the `port/3ds` branch. The current software checkpoint is M7: a pinned,
legal PC-side workflow for producing and validating the required O2R archives.
M6 hardware memory calibration remains pending; the project owner is the
real-hardware tester.

No milestone is considered complete until its acceptance criteria are backed
by reproducible evidence. This is not yet a playable PaperBoat port.

## Target

- devkitARM, libctru, citro3d, and citro2d
- `.3dsx` as the canonical Homebrew Launcher package
- `.3ds` for Folium/emulator QA and `.cia` for optional CFW installation
- Old Nintendo 3DS performance and memory baseline
- 400x240 top-screen gameplay
- 320x240 bottom-screen PaperBoat configuration menu
- PC-generated legal `.o2r` assets loaded from SDMC/RomFS

Build instructions are in [docs/BUILDING.md](docs/BUILDING.md). The M7 asset
workflow is documented in
[docs/M7_ASSET_PIPELINE.md](docs/M7_ASSET_PIPELINE.md).

## Legal asset policy

This repository must not contain Nintendo ROMs, copyrighted game assets,
extracted `.o2r` packages, encryption keys, or other proprietary material.
Required game assets are generated by the user on a PC from a legally obtained
copy and are never committed or uploaded to CI.

## Accuracy policy

Build, link, boot, rendering, gameplay, audio, performance, and hardware-
compatibility claims must be backed by reproducible evidence. The project will
not represent an untested milestone as complete.
