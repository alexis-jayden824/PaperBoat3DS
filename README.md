# PaperBoat3DS

An experimental native Nintendo 3DS port of PaperBoat.

## Status

Pre-bootstrap. Development follows the documented M0-M24 roadmap on the `port/3ds` branch. A milestone is not considered complete until its acceptance criteria are reproduced with the appropriate toolchain; hardware milestones require verification on a real Nintendo 3DS by the project owner.

## Target

- devkitARM, libctru, citro3d, and citro2d
- `.3dsx` homebrew first
- Old Nintendo 3DS performance and memory baseline
- 400x240 top-screen gameplay
- 320x240 bottom-screen PaperBoat configuration menu
- PC-generated legal `.o2r` assets loaded from SDMC/RomFS

## Legal asset policy

This repository must not contain Nintendo ROMs, copyrighted game assets, extracted `.o2r` packages, encryption keys, or other proprietary material. Required assets are generated by the user on a PC from a legally obtained copy and are never committed.

## Accuracy policy

Build, link, boot, rendering, gameplay, audio, performance, and hardware-compatibility claims must be backed by reproducible evidence. The project will not represent an untested milestone as complete.
